# Claim Ledger

**Rule: a row enters this file only after Stew has opened the primary source.**
Nothing from `candidates.md` is promoted automatically, and nothing Claude says
about a paper's contents is a source. C6 applies to every row.

**One claim per row.** If you cannot name the sentence in our paper that a row
supports, you probably do not need the row.

---

## Columns

| Field | Meaning |
|---|---|
| `ID` | `<cluster>-<n>`, matching `candidates.md` where applicable |
| `Claim` | One sentence, in your words |
| `Source` | Full reference as it will appear in the bibliography |
| `Anchor` | Section, figure, or page where the claim appears |
| `Depth` | `abstract` / `method` / `full` — how much you actually read |
| `Read` | Date |
| `Stance` | `supports` / `threatens` / `neutral` |
| `Supports which sentence of ours` | Or `none yet` |
| `Notes` | Caveats, disagreements with the source, measurement details |
